# 聞き取りの調査 (2026-11-21)

韓国語と中国語の読みを、話せる人に聞いてもらう。ユーザーは両方とも話せないので、友人に頼む。

- 韓国語: https://claude.ai/artifact/7zLXp5bA6L28wanC3Tif8y (ページは韓国語)
- 中国語: https://claude.ai/artifact/BezEtJWo5Y8v1ADrFBzLrS (ページは中国語)

各項目に同じ歌詞の音が二つ (①②) あり、聞き手は「① / ② / 같다・一样 (same) / 둘 다 이상・都不对 (both)」を選び、
メモを書き、答えをテキストでコピーしてユーザーに送る。答えの行は `K1 햇살이 창문을 두드리면: 2 | メモ` の形。

どちらが今の Cantoria (`21b2d1a`) の読みかは聞き手に伏せてある。下の「今」の列がその番号。
もう一方は、K1〜K7 は終声を運ばない読み (音符の間を 2 ms 空けて運ばせなかった)、K8〜K11 は正しい読みを手で書いたもの、
Z1〜Z7 は一字ずつの読み (語で読む前の Cantoria と同じ) を pinyin で渡したもの。
声は diffsinger/Nishiren。音は描くたびに少し変わる。

- K1〜K7: 「今」が選ばれれば、音符をまたぐ連音は正しい。
- K8〜K11: まだ扱っていない音変化。「今でない方」が選ばれるのが当然で、知りたいのはメモ (どれほど気になるか)。
  K8 꽃잎이 は、hyphen なしでも運ぶようにしたため 꼬치피 と歌う (正しくは 꼰니피)。語の境を越えて運んでいる。
- Z1〜Z7: 「今」が選ばれれば、語で読む多音字は正しい。中国語のページは声調を気にしないよう頼んである (歌では旋律が決める)。

**調査を出した後の変更** (`21b2d1a` の後): 助詞・語尾でない音節の前では代表音で運び、ㅣ・y 母音の前では運ばなくした。
K8 は 꽃이피 に (꼰니피 はまだ)、K11 は 꼬뒤에 になった (K11 は「もう一方」と同じ読み)。K1〜K7 と K9・K10 は変わらない。
その後さらに、終声と次の子音の音変化 (鼻音化・激音化・流音化・濃音化) を入れた。K9 は 밤만머거요、K10 は 추카해요 に
なり、どちらも「もう一方」と同じ読み。K1 は 햇싸리 (濃音化) に変わった。K8〜K11 と K1 の答えは、出した時点の読みについてのもの。

- 2026-11-27 に今の `ChinesePhonemizer.Read` で 7 つとも読み直し、表の「今の読み」と同じだった (Z4 は shui zhao)。
  **文字の上の読みは 7 つとも正しい。**
- 目立つ型: 「今」が ① の Z2・Z3・Z5 は 3 つとも「今」が選ばれ、「今」が ② の Z1・Z4・Z6・Z7 は 4 つとも
  選べなかった (same か both)。違いが zh/ch (长 重) や 着・觉 の母音にあるため、日本語・韓国語の声の Nishiren が
  中国語の音をはっきり歌い分けられていない、というのが一番ありそうな説明。① ② を作る手違いの可能性も残る
  (音は描くたびに変わるので、mp3 の hash では確かめられない)。
- 確かめるなら: Z1・Z4・Z6・Z7 を中国語の声 Qixuan で描き直して、もう一度聞いてもらう。
